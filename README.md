# RADIESTESIA SOLAR — versão PDF + DOCX editável

## Exportação
- PDF: A4, margens padrão, escala 100% e gráficos de fundo ativados.
- DOCX (editável): botão próprio no topo e no final do relatório. O DOCX prioriza edição e preserva a estrutura de títulos, textos e tabelas; o PDF permanece como versão visual final.

## Ajuste de paginação desta versão
- “Seu tratamento” continua iniciando em página própria no PDF.
- “Observações finais” agora faz parte do próprio bloco “Seu tratamento”, aproveitando o espaço que restar na página. Se não couber, passa inteira para a página seguinte, evitando uma página quase vazia só para uma linha.
- “Continuidade do cuidado” e a assinatura permanecem no encerramento.
